## 5. TIPOGRAFÍA

### Familia Tipográfica Principal

**Nombre:** Inter  
**Origen:** Google Fonts  
**URL:** https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700;800

**Pesos disponibles:** 300, 400, 500, 600, 700, 800

**Ventajas:**
- Diseñada para web
- Excelente legibilidad en pantalla
- Buena cobertura de caracteres
- Rendimiento optimizado

**Fallback:** `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`

### Familia Tipográfica Secundaria (Opcional)

**Nombre:** Poppins  
**Uso:** Alternativa para énfasis en branding o secciones especiales  
**No es obligatorio** - usar con moderación

### Reglas Tipográficas

✅ **Reglas a Seguir**

1. Usar **Inter** como fuente principal en TODOS los elementos
2. Mantener **jerarquía clara**: H1 > H2 > H3 > Body
3. Usar **pesos consistentes**: 400 para body, 600+ para headings
4. Mantener **altura de línea adecuada**: mínimo 1.4 para lectura
5. Aplicar **responsive typography**: tamaños menores en mobile
6. Garantizar **contraste suficiente**: 4.5:1 mínimo (WCAG AA)
7. Respetar **espaciados de línea**: coherencia visual

❌ **Reglas a Evitar**

1. NO cambiar la familia tipográfica sin aprobación
2. NO usar tamaños menores a 12px en texto de cuerpo
3. NO combinar muchas familias diferentes
4. NO usar solo mayúsculas en párrafos largos
5. NO ignorar espaciados de línea
6. NO aplicar efectos de sombra o distorsión
7. NO variar aleatoriamente los pesos

## 10. REGLAS DE MARCA

### Reglas del Logo

✅ **Debe**
- Mantener proporciones originales
- Usar colores oficiales (#004B87 y #00BCD4)
- Respetar espacios mínimos (16px)
- Escalar proporcionalmente
- Usar variantes apropiadas según fondo

❌ **No debe**
- Estirar o distorsionar
- Cambiar colores sin aprobación
- Agregar efectos visuales
- Colocar sobre fondos sin contraste
- Combinar confusamente con otros elementos
- Rediseñar o simplificar sin autorización
- Modificar tipografía incluida
- Eliminar el mapa de Baja California

### Reglas de Color

✅ **Debe**
- Usar #004B87 como primario
- Usar #00BCD4 como acento
- Mantener paleta consistente
- Verificar contraste WCAG AA
- Usar tema claro por defecto

❌ **No debe**
- Inventar colores "cercanos"
- Cambiar proporciones de colores
- Saturar o desaturar sin razón
- Usar Azul Marino + Cyan juntos para texto
- Comprometer accesibilidad por estética

### Reglas de Tipografía

✅ **Debe**
- Usar Inter como primaria
- Mantener jerarquía clara
- Respetar pesos definidos
- Usar altura de línea mínima 1.4
- Aplicar responsive typography

❌ **No debe**
- Cambiar familia tipográfica
- Mezclar demasiadas fuentes
- Usar tamaños menores a 12px
- Violar jerarquía de heading levels
- Aplicar efectos de distorsión

### Reglas de Marca General

✅ **Debe**
- Mantener coherencia visual en todo
- Documentar cambios
- Obtener aprobación para variantes
- Preservar archivos originales
- Comunicar cambios al equipo

❌ **No debe**
- Hacer cambios sin documentación
- Crear versiones no autorizadas
- Mezclar identidades de marca
- Abandonar estándares de marca
- Usar recursos de baja calidad
